Folder `config/branding/` — tu umieść własne zasoby brandingu.

Wymagane pliki (sugestia):
- `logo.png` — główne logo instalatora i ISO
- `splash.png` — ekran powitalny live
- `wallpaper.jpg` — domyślna tapeta

Upewnij się, że posiadasz prawa do używanych grafik. Możemy wygenerować prosty placeholder lub skrypt do tworzenia podstawowego motywu.
